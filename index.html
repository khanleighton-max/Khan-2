Set up the tool

This talks to Claude from your browser, so it needs your own Anthropic API key. It stays on this device and is only ever sent to Anthropic.

Get one at console.anthropic.com. Set a low spend limit while you try it.
A walk down the line is many short messages, so Sonnet keeps cost sensible.
Optional but recommended. Free account at elevenlabs.io → your profile → API key. With it, each person speaks in a natural human voice on any device. Without it, the app uses your device's built-in voice.
Never paste your keys into a chat or share this file with a key saved in it. A browser page can't hide a key — treat it like cash and keep a spend cap on it.
